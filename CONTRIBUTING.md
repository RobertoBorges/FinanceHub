# Contributing to FinanceHub

Thank you for your interest in contributing to FinanceHub! This repository serves as the **feature tracker and community request hub** for FinanceHub. Contributions here focus on documentation, roadmap suggestions, and issue triage.

---

## Ways to Contribute

### 💡 Request a Feature
1. Check the [open issues](../../issues) to see if your idea already exists.
2. If not, click **[New Issue](../../issues/new/choose)** and choose the **Feature Request** template.
3. Fill in the template completely — the more detail, the better.

### 🐛 Report a Bug
1. Check the [open issues](../../issues) to avoid duplicates.
2. Click **[New Issue](../../issues/new/choose)** and choose the **Bug Report** template.
3. Provide clear steps to reproduce, expected behavior, and actual behavior.

### 🗳️ Vote on Existing Issues
Browse [open issues](../../issues) and use the 👍 reaction on the ones you care about most. This helps prioritize what gets built next.

### 💬 Join the Discussion
Comment on existing issues to add context, share use cases, or suggest improvements to proposed features. Constructive feedback is always welcome.

### 📝 Improve the Documentation
If you notice the README, roadmap, or feature descriptions are outdated or incorrect:
1. Fork this repository.
2. Create a branch: `git checkout -b docs/your-improvement`.
3. Make your edits and open a Pull Request with a clear description.

---

## Issue Guidelines

To keep things organized and actionable, please follow these guidelines:

- **One idea per issue.** If you have multiple feature requests, open separate issues.
- **Search before posting.** Duplicate issues will be closed with a reference to the original.
- **Be specific.** Vague requests like "make it better" are hard to act on. Describe exactly what you need and why.
- **Stay respectful.** This is a community space. Treat others the way you'd like to be treated.

---

## Code of Conduct

All participants are expected to follow the [GitHub Community Guidelines](https://docs.github.com/en/site-policy/github-terms/github-community-guidelines). Harassment, spam, or abusive behavior will not be tolerated.
