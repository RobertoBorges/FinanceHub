# FinanceHub 📊

> **Feature tracker & community request hub for FinanceHub**

FinanceHub is the central place where you can:
- 📋 Browse the **current and planned features** of FinanceHub
- 💡 **Request new features** by opening a GitHub Issue
- 🐛 **Report bugs** you find in FinanceHub
- 🗳️ **Vote** on existing requests by reacting with 👍

---

## What is FinanceHub?

**FinanceHub** is a stock portfolio management application that helps individuals and small teams track investments, monitor market performance, and make informed financial decisions.

---

## ✅ Current Features

### Portfolio Management
- Add, edit, and remove stock positions from your portfolio
- Track purchase price, quantity, and current market value
- Support for multiple portfolios per user
- Portfolio summary with total value and profit/loss

### Market Data
- Real-time stock price quotes
- Historical price data and charts
- Support for major stock exchanges (NYSE, NASDAQ, etc.)
- Currency conversion for international stocks

### Performance Analytics
- Daily, weekly, monthly, and yearly performance reports
- Gain/loss calculations per position and per portfolio
- Dividend tracking and yield calculations
- Comparison against market benchmarks (e.g., S&P 500)

### Alerts & Notifications
- Price alerts (above/below a threshold)
- Portfolio value threshold alerts
- Email and in-app notifications

### Import / Export
- Import positions from CSV files
- Export portfolio data to CSV and PDF
- Integration with common brokerages for automatic import

### User Experience
- Responsive web interface (desktop and mobile)
- Dark mode support
- Multi-language support (English, Portuguese)
- Secure authentication with support for 2FA

## 💡 How to Request a Feature

1. **Search first** – Check the [open issues](../../issues) to see if your idea has already been suggested.
2. **Open a new Issue** – Click **[New Issue](../../issues/new/choose)** and select the **Feature Request** template.
3. **Describe your idea** – Fill in the template with as much detail as possible:
   - What problem does it solve?
   - How would you like it to work?
   - Any examples or references?
4. **Engage** – Comment on and react (👍) to issues to help prioritize the most wanted features.

---

## 🐛 How to Report a Bug

1. **Search first** – Check [open issues](../../issues) to avoid duplicates.
2. **Open a new Issue** – Click **[New Issue](../../issues/new/choose)** and select the **Bug Report** template.
3. **Provide details** – Include steps to reproduce, expected behavior, actual behavior, and screenshots if applicable.
